# Iteration comparison

The four kit components rendered under core and every emitted iteration, side
by side, from one component build. The iteration columns carry the same
`data-iteration` attribute the toolbar applies to `<html>` — proving that an
iteration is a token remap, not a component fork.

For live switching, use the **Iteration** toolbar on any component story.
