# Tokens

Generated from the W3C DTCG source under `packages/tokens/tokens/` at build
time — this page is never hand-maintained. Primitives are the raw,
usage-neutral values; semantic tokens are the role-named mappings components
consume. Per-iteration remappings of the semantic tier are shown in the
iteration columns.
